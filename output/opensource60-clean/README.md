## 导入建议

1. 新建独立知识库，建议名“开源60问-HQ结构化测试”，仅上传knowledge-import.txt。
2. 使用通用分段；自定义分段标识符填写 `<<<OS60_CHUNK>>>`（无需反引号）。每个标识符分隔一个带独立来源信息的片段。
3. 最大分段长度设为2000或更大，重叠为0。若UI使用不同长度单位，以预览结果为准：应得到550段，且段首来源信息未被拆开。不要继续沿用1024的上限，因为最长片段有1220字符。
4. 避免删除换行或改写内容的额外清洗。预览先检查5.3为书页20/PDF38；5.4分成书页20、21两部分；第23问题名与23.2小节名分开。
5. 预览片段数或来源字段不符合预期时，先检查分隔符和长度，勿重新逐题添加关键词。
6. 沿用已确认基线：高质量、text-embedding-v4、向量检索、Top K10、分数阈值关闭。应用节点使用语义权重1/关键词0，DeepSeek Flash思考模式False。导入本身不修改应用配置。
7. 新库会产生一次嵌入用量；本交付未对Dify账户执行导入或扣费操作。

这是文字检索基线，不是完整图像知识库。除表20-2外，图片中的文字、箭头、坐标及图形关系未做全面转写；相关原页截图已保留。复杂合并单元格和原书本身的事实准确性仍需专门校核。图表相关问题不应仅凭自动转写得出结论。

跨页小节保留各页独立来源，因此同一小节可有多个片段，跨页句子也可能分布在相邻片段。不能只凭标题与页码补齐就宣称所有问答已通过；导入后应用固定测试集做整体对照，不逐题修补。
